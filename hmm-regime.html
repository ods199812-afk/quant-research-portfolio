01 / Question & design

Does a changing market call for changing factor weights?

A static equity factor model assumes one set of coefficients remains useful across market conditions. This project tests a more adaptive approach: infer a latent state from market-wide observations and use historical, state-dependent factor IC estimates to score individual stocks.

State representation

Market breadth, cross-sectional return dispersion, average and absolute returns, with rolling aggregates derived from the equity universe.

Equity factor universe

10/20-day momentum and volatility, valuation, profitability, growth, dividend yield, beta and sales growth expectations.

Evaluation setup

Chronological training/test split, a 20-trading-day return target, and a top-50 long-only portfolio rebalanced approximately every 20 trading days.

02 / Method

Separate market-state inference from stock selection

Fit, then filter

The Gaussian HMM and feature scaler are fitted on the training segment. Test-period state probabilities are estimated causally using observations available up to each date, rather than whole-sequence smoothing. Train-period factor ICs determine state-specific coefficient vectors.

Compare three allocation rules

Soft: average state-dependent coefficients using filtered probabilities. Hard: use coefficients of the most probable state. Static: hold coefficients fixed using mean training-period IC, without HMM inputs.

03 / Empirical comparison

Preliminary historical results

After correcting the forward-return label and replacing whole-sequence test inference with causal filtering, the prototype was rerun with a static factor-weight baseline. The HMM-conditioned portfolios showed higher historical returns and return/volatility ratios than the static approach in this particular test window.

What the comparison suggests. Soft and Hard HMM variants track closely, consistent with strongly concentrated state probabilities (average maximum filtered posterior ≈95.5% across 393 test observations). The static baseline diverges more substantially, providing a useful starting point for evaluating whether regime conditioning adds value.
04 / Research practice

Implementation lessons and boundaries

Time-aware engineering

The original experiment prompted two substantive fixes: aligning 20-day forward-return targets to dates after the signal, and using causal HMM filtering for test-period state estimation. These fixes were made before the reported three-way comparison.

Why this is still a prototype

Point-in-time fundamental availability, missing-target universe selection, implementation timing, return accounting and transaction costs have not all been independently audited. The sample also includes only 19 rebalances. Results are not evidence of investable alpha.

The central takeaway is methodological: a model can identify state-dependent factor relationships, but the investment significance of those relationships must be established with time-consistent evaluation and credible simpler baselines.

05 / Implementation

Research from raw data to portfolio diagnostics

The Python project is organized into data construction, chronological splitting, latent-state inference, dynamic factor scoring, portfolio simulation and research notebooks. This case study presents selected results without publishing the underlying licensed raw market data.
